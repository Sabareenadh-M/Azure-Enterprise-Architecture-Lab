A collection of Azure enterprise architecture lab projects covering network design, identity management, domain joining, and web server deployment.

## Overview

This repository documents a multi-project Azure lab that demonstrates enterprise-style cloud infrastructure patterns, including:

- Hub-and-spoke network design
- Active Directory Domain Services deployment
- Windows workstation and member server integration
- IIS web server deployment and internal access testing
- Hybrid cloud architecture concepts

## Projects Included

### Project 1: Secure Hub and Spoke Network Architecture in Azure
- Azure Virtual Networks
- VNet peering and routing
- Azure Bastion
- Network Security Groups
- Private IP addressing

### Project 2: Building an Active Directory Domain Controller in Azure
- Windows Server administration
- AD DS installation
- DNS configuration
- Identity and access management

### Project 3: Integrating Workstations and Member Servers into Active Directory
- Domain join configuration
- Active Directory Users and Computers validation
- IIS deployment
- Internal network access testing

### Project 4: Hybrid Cloud Integration
- Hybrid cloud architecture concepts
- Enterprise connectivity patterns
- Cloud and on-premises integration planning
